# Curated Documentation & Resource Directory

This directory provides the high-signal resources required for the masterclass. Priority is always given to official Apple sources.

## 1. Official Apple Foundations (Essential)
*   **Swift.org:** [The Swift Programming Language](https://docs.swift.org/swift/) — The definitive guide to the language.
*   **Apple Developer Documentation:** [Documentation Home](https://developer.apple.com/documentation/) — The source of truth for all frameworks.
*   **Human Interface Guidelines (HIG):** [Apple HIG](https://developer.apple.com/design/human-interface-guidelines/) — Essential for UX/UI design.
*   **WWDC Videos:** [Apple Developer Videos](https://developer.apple.com/videos/) — The best way to learn new APIs as they are released.

## 2. Framework-Specific Deep Dives (Essential)
*   **SwiftUI:** [SwiftUI Documentation](https://developer.apple.com/documentation/swiftui)
*   **SwiftData:** [SwiftData Documentation](https://developer.apple.com/documentation/swiftdata)
*   **RealityKit:** [RealityKit Documentation](https://developer.apple.com/documentation/realitykit)
*   **Swift Testing:** [Swift Testing Guide](https://developer.apple.com/documentation/swift-testing)

## 3. Advanced Engineering Resources (Supplementary)
*   **Swift Evolution:** [Swift Evolution Proposals](https://github.com/apple/swift-evolution) — See how the language is evolving and why.
*   **Point-Free:** [Point-Free](https://www.pointfree.co/) — Advanced functional programming and The Composable Architecture (TCA).
*   **Hacking with Swift:** [Paul Hudson's Tutorials](https://www.hackingwithswift.com/) — Excellent for practical, project-based learning.
*   **Swift Lee:** [Antoine Winfield's Blog](https://swiftlee.com/) — Deep dives into specific UIKit/SwiftUI challenges.

## 4. Tooling & Environment (Essential)
*   **Git Documentation:** [Pro Git Book](https://git-scm.com/book/en/v2) — The complete guide to version control.
*   **Xcode Instruments:** [Performance Tuning Guide](https://developer.apple.com/documentation/instruments) — How to use the profiling tools.

## 5. Spatial Computing Specialization (Advanced)
*   **VisionOS Design:** [Design for visionOS](https://developer.apple.com/design/visionos/)
*   **Reality Composer Pro:** [User Guide](https://developer.apple.com/documentation/realitycomposerpro)
*   **USDZ Format:** [Pixar USD Specification](https://openusd.org/) — Understanding the underlying 3D format.
