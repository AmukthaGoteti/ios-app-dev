# Detailed Weekly Study Plan: Apple Ecosystem Engineering

This plan translates the Master Syllabus into a concrete schedule. The estimated hours assume a dedicated learning pace.

## 1. Track Definitions
*   **Track A (Absolute Beginner):** Starts from Phase 0. Full journey. (~25-30 hours/week)
*   **Track B (Polyglot):** Starts from Phase 1. Skips CS basics. (~20-25 hours/week)
*   **Track C (Apple Dev):** Starts from Phase 3 (SwiftUI) and focuses on Phase 1.6 (Concurrency), Phase 7 (visionOS), and Phase 10 (Architecture). (~10-15 hours/week)
